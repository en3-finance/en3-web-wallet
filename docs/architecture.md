# Architecture

The web wallet demo is planned as a Vite, React, and TypeScript application that demonstrates wallet interface flows through public, documented boundaries.

## Planned Components

- Browser UI shell.
- Demo mode.
- EVM-compatible chain configuration.
- Transaction review screens.
- Placeholder platform API client.
- viem/wagmi or equivalent EVM tooling.

## Private Boundary

Production custody, signing internals, backend services, compliance controls, and customer-specific integrations are not part of this public repository.
