# Reference Screens

| Screen | Demonstrates |
| --- | --- |
| Account Overview | Customer account, wallet state, and stablecoin balances. |
| Deposit | Deposit address, network, asset, and copy/share behavior. |
| Send | Destination, amount, network, memo, and review. |
| Transaction Status | Submitted, requires approval, approved, broadcast, settled, failed. |
| Risk / Approval | User-facing pending state when review is required. |
| Support / Recovery | Help states without exposing custody operations. |

Screens should use mock data and sandbox API responses only.
