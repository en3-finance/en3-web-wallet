# Demo Scope

The web wallet repository is a public demo surface.

## In Scope

- Demo browser wallet screens.
- Demo mode.
- Placeholder EVM network configuration.
- Documented API boundary examples.
- Interface patterns for enterprise wallet infrastructure evaluation.

## Out Of Scope

- Production custody.
- Real MPC signing.
- Compliance decision logic.
- Production hosted wallet deployments.
- Customer-specific implementations.
