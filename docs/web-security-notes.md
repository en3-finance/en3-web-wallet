# Web Security Notes

The web wallet repository is a public demo interface, not production custody infrastructure.

## Browser Demo Rules

- No seed phrases in demo code.
- No production keys.
- No production custody.
- No sensitive customer data.
- No backend secrets.
- Treat browser wallet demos as non-custodial UI examples unless connected to a secure backend in a private environment.

## Configuration

Use placeholders for API hosts, RPC URLs, and chain parameters unless safe public demo values are explicitly approved later.
